## 📌 Project Overview

InterviewAI is an AI-powered mock interview platform designed to help students and job seekers practice interviews and understand their interview performance.

The system generates role-specific interview questions using a Large Language Model through LangChain, evaluates the candidate's answers using AI, and calculates an overall interview readiness score using Fuzzy Logic.

The platform provides detailed feedback, performance analysis, strengths, improvement areas, and an interview report.

---

## 🎯 Objectives

- Generate personalized interview questions based on the candidate's resume and selected role.
- Conduct an interactive mock interview.
- Evaluate candidate answers using AI.
- Analyze technical knowledge, relevance, communication, completeness, and confidence.
- Calculate an interview readiness score using Fuzzy Logic.
- Provide personalized feedback and improvement suggestions.
- Generate a final interview performance report.

---

## ✨ Features

### 📄 Resume-Based Interview
Upload your resume and provide your target job role to generate relevant interview questions.

### 🤖 AI Question Generation
LangChain and Gemini are used to generate role-specific interview questions.

### 🎤 Mock Interview
Candidates can answer generated questions through an interactive interview interface.

### 🧠 AI Answer Evaluation
Each answer is evaluated based on:

- Technical Knowledge
- Relevance
- Communication
- Completeness
- Confidence

### 📊 Performance Analysis
The system provides question-wise scores and overall performance analysis.

### 🔮 Fuzzy Logic Readiness
Fuzzy Logic combines interview performance parameters to determine the candidate's readiness level.

### 📑 Interview Report
A final interview report summarizes the candidate's performance, strengths, weaknesses, and recommendations.
